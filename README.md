# Lune — companion interface concept

Independent speculative sample built by Codex for Beijing Fujie Technology to demonstrate a directly implementable frontend for an AI companion product. It is not a commissioned project, accepted client delivery, revenue, or evidence of prior client experience.

Includes responsive conversation layout, three illustrated scenes, two palettes, message composition, keyboard submission, scripted replies, fresh-conversation reset, saved moments, and an accessible about dialog. Original SVG illustration; no stock portrait or client assets. Only messages in the current tab's memory are used; no backend, analytics, model call, or message upload. Optional Google Fonts requests contain no chat content; system fonts are available as a fallback.

Open `index.html` directly or serve the directory with a static server. No build dependencies. Source is supplied for inspection and adaptation.

This sample demonstrates interface implementation only. Real production work requires the client's page list, source framework, screenshots/brand assets, and acceptance criteria. No performance, accessibility conformance, or customer acceptance claim is made solely from this concept.
